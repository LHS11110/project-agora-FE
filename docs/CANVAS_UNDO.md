# 캔버스 실행 취소

하단 도구 모음의 실행 취소 버튼이나 Ctrl+Z(Windows/Linux), ⌘+Z(macOS)로 최근 로컬 객체 변경을 되돌린다. 이력 횟수에는 제한이 없으며 현재 캔버스 화면을 떠나거나 새로고침하면 사라진다. 전체 캔버스를 복제하지 않고 변경된 객체 참조와 변경 필드만 보관한다.

생성, 삭제, 이동, 크기, 스타일, 텍스트·코드 내용, 텍스트 부분 색상이 대상이다. 포인터 조작 한 번과 방향키를 누르고 있는 동안의 반복 이동을 묶으며, 연속 입력은 짧은 간격의 같은 객체 변경을 묶는다. 실행 결과 갱신, 채팅, 댓글, 캔버스 관리 설정은 객체 실행 취소 이력에 포함하지 않는다. 텍스트·포스트잇·코드 편집 중의 Ctrl+Z도 해당 객체의 공동 편집 이력을 사용한다. 코드 에디터 우클릭 메뉴의 실행 취소도 같은 경로를 사용한다. 관련 이력이 없으면 다른 사용자의 입력이나 객체 생성까지 되돌리지 않는다. 채팅·설정 입력창은 기존 입력창의 실행 취소를 유지한다.

복원은 기존 서버 변경 큐에 새 변경으로 제출하므로 브로커의 저장·브로드캐스트 흐름을 그대로 따른다. 권한과 잠금 검사를 생략하지 않는다. 원격 변경은 이력에 추가하지 않으며, 같은 객체의 다른 필드는 보존한다. 일반 객체 필드가 이미 다른 값으로 바뀐 경우 복원을 중단하고 안내한다.

공동 텍스트는 로컬 변경 때 Automerge의 변경 연산을 읽어 삽입한 문자 ID, 삭제한 문자 ID·내용·색상, 색상 변경 대상 ID를 기록한다. 이력 묶음 안에서도 개별 변경을 역순으로 취소하여 중간에 들어온 원격 입력이 로컬 변경에 섞이지 않게 한다. 현재 문서에서 아직 보이는 내 문자 ID만 삭제하고, 내 삭제는 안정적인 커서 위치에 새 문자로 복원한다. 다른 사용자가 같은 문자를 독립적으로 삭제했다면 되살리지 않는다. 복원한 문자의 새 ID를 이전 ID와 연결해 다음 실행 취소도 동작하게 한다. 색상은 내가 지정한 값이 아직 유지되는 문자에만 이전 값을 적용하며 원격 삽입·재색칠은 유지한다.

예를 들어 빈 텍스트에 내가 `a`, 다른 사용자가 앞에 `b`를 입력해 `ba`가 되었을 때 내 실행 취소 결과는 `b`다. 동일한 글자, 글자 사이 원격 삽입, 한글·이모지에서도 문자열 검색 대신 문자 식별자를 사용한다. 과거 문서로 덮어쓰지 않고 현재 문서 위에 새 CRDT 변경을 생성한다. 과거 데이터처럼 텍스트 필드 전체가 별도 Automerge 객체로 교체되어 식별자를 공유하지 않는 경우에는 기존의 충돌 검사 방식으로 처리한다.

검증:

- `node --test tests/canvasUndoHistory.test.js`
- `tests/integration/canvas-undo.mjs`: 실제 React 동기화 훅, 모의 브로커 커밋, 5회 초과 이력, 다중 이동, 텍스트·색상·삭제 복원, 권한 검사.
- `tests/integration/canvas-undo-page.mjs`: 실제 캔버스 페이지의 단축키·도구 버튼과 모의 브로커 저장 흐름.

- `node --test tests/collaborativeUndo.test.js`: 동시 입력, 동일 문자, 부분 삭제·교체, 겹치는 원격 삭제, 색상, Unicode, 여러 단계 복원 ID 추적.
- `tests/integration/collaborative-undo.mjs`: 두 브라우저의 실제 텍스트 입력창·Monaco에서 `ba → b`, 브로커 CRDT 병합과 양쪽 화면 수렴.
