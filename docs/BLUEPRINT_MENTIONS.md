# 블루프린트 실행과 멘션

## 블루프린트 사용

툴 패널의 **자료·계산**에서 실행 객체, 코드 객체, 실행 결과 객체를 배치합니다.
연결 도구로 `실행 객체 → 코드 객체 → 실행 결과 객체` 방향의 화살표를 만듭니다.
코드 객체를 두 번 클릭해 언어와 코드를 편집한 뒤 실행 객체의 **코드 실행**을 누릅니다.
코드를 수정하는 것만으로는 실행되지 않습니다. 일반 연결 화살표의 `from → to`를 사용합니다.

여러 코드 객체는 연결 순서에 따라 한 번씩 실행되며, 한 코드에 여러 결과 객체를
연결하거나 결과 객체끼리 연결해 같은 출력을 여러 위치에서 볼 수 있습니다.
순환 연결은 실행 전에 거부합니다. VM 실행 실패·시간 초과가 발생하면 후속 코드 실행을
중단하고 연결된 결과 객체에 오류를 표시합니다.

Python, JavaScript, C, C++, Shell을 지원합니다. 인터넷이 차단된 캔버스별 VM의
파일 공간을 공유합니다. 각 코드 실행은 별도 프로세스여서 메모리 변수는 코드 사이에
유지되지 않습니다. 실행 그래프와 코드는 버튼을 누른 시점의 스냅샷을 사용하고,
실행 중 연결이 제거된 결과 객체에는 새 출력을 쓰지 않습니다.

한 번의 실행은 코드 최대 32개, 그래프 객체 최대 256개입니다. 결과 객체당 최근 실행
결과를 최대 32개, 직렬화 크기 512KiB 내에 보관합니다. 결과는 일반 캔버스 변경처럼
브로커와 C++ 서버를 통해 저장·공유되며 재접속 후에도 보입니다. 연결하지 않은 결과
객체에는 출력을 전달하지 않습니다. 결과 객체에는 마지막으로 저장된 결과가 유지됩니다.

## 서버가 관리하는 멘션

채팅과 객체 댓글에서 `@`로 닉네임과 태그 번호를 선택합니다.
서버는 실제 계정과 현재 캔버스·객체 권한을 검증해 멘션 대상을 확정합니다.
메시지의 `mentions[userId]`는 미읽음 `true`, 읽음 `false`입니다.
메시지와 사용자별 알림 인덱스는 같은 Redis 원자 작업으로 기록됩니다.
요청 재시도는 동일 메시지를 중복 추가하거나 읽음을 다시 미읽음으로 바꾸지 않습니다.

알림은 서버의 `mentions_get` 응답으로만 표시합니다. 알림을 눌렀을 때 해당 내용을
불러와 표시한 뒤 `mention_read`를 전송합니다. 알림 닫기도 읽음 처리합니다.
클라이언트의 로그인 ID 대신 인증된 브로커 세션의 사용자 ID로만 조회·변경합니다.
다른 탭과 기기에는 서버의 변경 신호를 전송하고, 재접속 시 다시 조회합니다.
세션 저장소나 로컬 저장소에 읽음 상태를 보관하지 않습니다.

오래된 멘션은 sequence 주변 메시지를 조회해 이동합니다. 객체 권한이 변경되거나 객체가
삭제되면 해당 댓글 알림은 조회 결과에서 제외합니다. 화면에는 최근 미읽음 최대 100개를
표시하고 읽은 알림이 제거되면 다음 알림이 조회됩니다. 현재 캔버스의 멘션을 표시합니다.
영구 스냅샷에는 사용자별 알림 상태를 `mention-states-b64`로 인코딩해 저장합니다.

## 검증

`node --test tests/*.test.js`와 C++ 브로커 검증·스냅샷·멘션 단위 테스트를 실행합니다.
실제 Redis 검증은 BE의 `python3 cpp/tests/mentions_redis_integration.py`를 사용하며
임시 키를 생성하고 정리합니다.

`tests/integration/blueprint-mentions.mjs`는 배포된 HTTPS 서비스에서 두 테스트 계정과
**전용 임시 캔버스**를 사용하는 실제 브라우저·VM 테스트입니다. 다음 환경 변수가 필요합니다.

- `AGORA_E2E_STATE`: 권한 0600 JSON 파일 경로. `{sessions:[{token,user},{token,user}], complete_id:임시캔버스ID}` 형식.
- 두 번째 계정은 임시 캔버스에 초대되어 있어야 합니다.
- `AGORA_E2E_PLAYWRIGHT_MODULE`: 설치된 playwright-core의 index.mjs 절대 경로.
- `AGORA_E2E_ORIGIN`: 배포 주소. 기본 `https://localhost`.
- `AGORA_E2E_CHROME`: Chrome 실행 경로. 기본 `/usr/bin/google-chrome`.

테스트는 임시 캔버스에 객체·댓글·메시지를 생성합니다. 실행 후 임시 캔버스를 삭제합니다.
토큰과 계정 상태 파일은 저장소에 추가하지 않습니다.
