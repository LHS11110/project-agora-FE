# Canvas Studio UI

사용자가 제공한 FigJam 스크린샷의 넓은 점 격자, 분리된 상단 컨트롤과 하단 도구 독을 참고했습니다.

- 밝은 중성색 및 다크 모드에 보라색 강조색을 사용합니다. 캔버스 편집 화면에만 적용합니다.
- 하단 독에서 선택·이동·드로잉·지우개·레이저·메모·도형·연결·텍스트·테이블·이미지에 접근합니다.
- 독의 도구 목록 버튼으로 기존 폴더 패널을 열 수 있습니다. PDF·링크·사용자 그룹과 폴더 관리도 기존 패널에서 계속 사용할 수 있습니다.
- 새 사용자는 탐색 창과 도구·대화 패널이 접힌 상태로 시작하고 속성 패널은 표시합니다. 기존 패널 저장 설정은 유지합니다.
- 상단 정보 및 협업 컨트롤, 우측 속성 패널, 하단 줌 컨트롤을 분리했습니다. 패널 크기 조절과 표시 전환을 유지합니다.
- 캔버스 위의 큰 blur나 backdrop-filter를 사용하지 않습니다. 편집 데이터 및 브로커 저장 경로는 변경하지 않습니다.

[실제 배포 화면](preview.png)

검증: Node 테스트 198개, 배포 빌드, 실제 Chrome의 도구 전환·패널 토글·속성 패널 리사이즈,
라이트/다크 및 390px 모바일의 도구 접근성·화면 경계, 객체 데이터 유지. 자세한 결과는 `validation.json`에 있습니다.

```sh
AGORA_SESSION_FILE=/private/session.json node scripts/test-canvas-studio-browser.mjs
```

브라우저 테스트의 세션 파일은 `token`, `user`, `canvas_id`를 포함하며 저장소에 넣지 않습니다.
테스트는 기존 캔버스를 읽기만 하며 객체를 생성·수정·삭제하지 않습니다.


## 중복 정보와 위젯 배치 정리

접속자는 우측 상단의 프로필 스택 한 곳에서 확인합니다. 마우스·키보드 포커스·터치로
프로필 카드를 펼치고 참여자 관리로 이동할 수 있습니다. 캔버스 멤버 명단 대신 브로커의
연결된 peer를 사용하고 같은 사용자의 여러 탭은 하나로 합칩니다.

설정 패널의 반복 참여자 목록·연결 상태·캔버스 통계, 하단 반복 설명, 설정 창의 revision,
사이드바의 반복 프로필·장식 문구를 제거했습니다. 배경색은 속성 패널에서만 조정합니다.
정상 동기화 안내는 숨기고 저장 대기·연결 복구·실패 안내는 유지합니다.

탐색 버튼을 제목 카드 안에 고정하고, 실제 편집 영역 너비에 따라 도구 독과 줌 컨트롤의
행을 분리합니다. 미니맵은 대화 패널 위의 공간을 사용하며 모바일 내용 패널은 하나씩 펼칩니다.

[프로필 카드 펼침](presence.png). 실제 브라우저에서 데스크톱·사이드바·패널 열림·정보 접힘·
태블릿·모바일 9개 조합의 기본 위젯 겹침 0건과 객체 원문 보존을 확인했습니다.
상세 검증은 `chrome-validation.json`에 기록했습니다.

```sh
AGORA_SESSION_FILE=/private/session.json node scripts/test-canvas-chrome-browser.mjs
```

## X·Y축 눈금

축 원점을 기준으로 논리 픽셀(px) 좌표를 표시합니다. 기존 원점(기본 작업 공간의 중심)과
X 오른쪽·Y 위쪽 양수 방향을 유지합니다. 표시 배율에 따라 1·2·5 × 10ⁿ 간격을 선택하며
소수 좌표와 음수도 표시합니다. 글자 크기는 화면에서 일정하게 유지합니다.

눈금은 화면 범위만 계산하고 카메라의 `agora-camera` 갱신에 맞춰 SVG 노드를 재사용합니다.
객체 수나 전체 세계 크기를 순회하지 않으며 축마다 최대 256개로 제한합니다.
X·Y축의 개별 표시 설정을 따르고 두 축을 끄면 눈금 갱신도 해제합니다.

```sh
AGORA_SESSION_FILE=/private/session.json node scripts/test-axis-ticks-browser.mjs
```
