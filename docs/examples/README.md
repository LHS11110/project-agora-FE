# 논리 회로 예시

배포된 캔버스: https://112.168.71.147/canvases/2039

도형 도구의 **논리 회로**에서 AND, OR, NOT, XOR, NAND, NOR, XNOR,
BUFFER, 전가산기 블록을 선택할 수 있습니다. 기존 도형처럼 이동, 크기 변경,
회전, 손그림 스타일, 테두리와 채우기 설정을 지원합니다.

게이트에 연결선을 만들면 입력·출력 핀에 붙습니다. 연결선을 선택한 뒤 설정
패널의 **논리 회로 배선**에서 사용할 핀을 지정할 수 있습니다. 전가산기는
입력 A/B/Cin, 출력 S/Cout을 제공합니다. 자동 선택은 상대 객체와 가까운
핀을 사용합니다. 회전·이동·크기 변경 시에도 지정한 핀을 따라갑니다.
배선에는 기본적으로 화살표 머리가 없으며 기존 곡선 조절도 사용할 수 있습니다.

`8-bit-full-adder.canvas.json`은 편집 가능한 213개 객체로 구성됩니다.

- 입력 A는 초록 행, B는 파랑 행에 비트 번호·값이 적힌 단자로 표시합니다.
  진한 칸은 1, 흰 칸은 0이며 캐리 입력은 별도 주황색 단자입니다.
- FA0부터 FA7까지 연결한 8비트 리플 캐리 전가산기. 왼쪽이 LSB입니다.
- 각 FA 내부의 XOR 2개, AND 2개, OR 1개로 이루어진 1비트 회로.
- 논리 게이트 기호 모음, 진리표, 자리올림 예시.

표시된 입력은 53 + 27 + Cin(0)이며 합계는 80, Cout은 0입니다.
색상과 숫자는 설명용 고정 예시입니다. 입력 변경에 따른 자동 시뮬레이터는
포함하지 않습니다. 분기점의 점으로 전기적 연결을 표시하며, 점 없이
교차하는 배선은 서로 연결되지 않습니다.

재생성:

```sh
node scripts/generate-adder-canvas.mjs
node --test tests/logicGates.test.js tests/hostCanvas.test.js
```

실제 저장은 앱의 Canvas as Code API를 통해 일반 편집과 같은 브로커·호스트
경로를 사용합니다. `scripts/create-adder-canvas-browser.mjs`는 별도로 준비한
소유자 전용 세션 파일(`ADDER_SESSION_FILE`)을 사용하며, 지정한 새 캔버스에만
적용해야 합니다. 세션 파일이나 인증 토큰은 저장소에 포함하지 않습니다.

검증: Node 테스트 전체 155개 통과, 논리 게이트 핀/이동/회전/배선 CRDT 저장
검증, 1비트 회로 실제 연결 그래프의 8가지 진리표 검증, 8비트 입력
131,072개 조합 검산. 배포 후 실제 브라우저에서 213개 객체의 서버 승인,
RedisJSON 저장과 새로고침 후 핀 정보 복원, 페이지 오류 없음을 확인했습니다.
