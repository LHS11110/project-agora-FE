# 캔버스 비밀번호 4시간 인증

공개 비밀번호 캔버스에서 비밀번호 인증에 성공하면 서버가 발급한 입장 인증 토큰을 저장한다. 원문 비밀번호는 저장하지 않는다. 인증 토큰은 사용자·캔버스·비밀번호 변경 버전 및 토큰 세대에 묶여 있으며 최초 발급 시점부터 4시간 동안 유효하다. 재사용·새로고침·재입장·재연결로 유효 시간이 늘어나지 않는다. WebSocket 토큰도 이 인증의 남은 시간까지만 유효해 4시간 만료 뒤에는 비밀번호를 다시 확인한다. 접속 중 토큰을 갱신하던 임시 세션 API도 제거했다. 이전 세대의 30분 인증 토큰은 거부되고 새 비밀번호 인증이 필요하다.

클라이언트는 같은 사용자/캔버스의 유효한 인증을 새 입장에서도 재사용한다. localStorage와 sessionStorage를 사용하므로 같은 브라우저의 다른 탭에서도 재사용할 수 있다. 만료되거나 서버가 거부하면 양쪽 저장소에서 제거하고 가려진 비밀번호 입력창을 다시 연다. 비밀번호 해제 시에도 저장된 인증을 지운다. 비밀번호 변경이나 접근 권한 회수는 기존 서버 검증을 그대로 따른다.

`tests/canvasAccess.test.js`: 사용자/캔버스 분리, 탭 간 공유, 만료/잘못된 인증 제거, 최초 인증 후 정확히 4시간 경계와 재사용 시 만료 연장 방지.

`tests/integration/canvas-password.mjs`: 실제 캔버스 화면과 격리된 API/브로커 대역으로 잘못된 비밀번호 재시도, 재연결·새로고침·재입장·새 탭의 인증 재사용, 만료 및 서버 거부 후 재입력, 취소를 검증한다.
