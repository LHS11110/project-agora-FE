# Project Agora 구현 및 활용 안내

Project Agora는 여러 사용자가 하나의 웹 캔버스에서 자료를 배치하고, 편집 내용을 실시간으로 공유하는 협업 서비스입니다. 회의 보드, 수업 자료, 시스템 설계도, 코드 실험 문서를 같은 캔버스에서 구성할 수 있습니다.

## 시작하기

1. 로그인한 뒤 **캔버스 검색** 화면에서 캔버스를 만들거나 접근 권한이 있는 캔버스를 엽니다. 비밀번호가 설정된 캔버스는 입장 시 비밀번호를 입력합니다.
2. 작업 화면의 도구 패널에서 도형, 포스트잇, 내용 등의 도구를 선택해 캔버스에 배치합니다. 텍스트와 수식은 해당 객체를 두 번 클릭해 편집하고, **연결** 도구로 객체 사이의 관계를 표시합니다.
3. **손** 도구로 화면을 이동하고 상단의 **+**, **−**, **맞춤**으로 배율을 조절합니다. 미니맵으로 먼 위치에 이동하거나 **앵커** 도구로 자주 찾는 위치를 저장할 수 있습니다.
4. 다른 사용자가 같은 캔버스에 입장하면 권한 범위 안에서 편집 내용과 커서 위치를 공유합니다. 캔버스 관리 화면에서 참여자와 그룹을 관리할 수 있습니다.

## 이용할 수 있는 기능

### 화면 이동과 객체 편집

- **손·미니맵·앵커** — 손 도구로 화면을 끌어 이동합니다. 멀리 떨어진 작업 구역은 미니맵에서 찾고, 자주 돌아가는 위치는 앵커 도구로 클릭해 개인 위치로 저장합니다.
- **확대·격자·좌표축** — 상단의 **+ / − / 맞춤**을 사용합니다. 최대 배율은 1600%입니다. **격자** 버튼으로 점 표시를 전환하고, 우측 설정에서 가로·세로 간격과 격자 맞춤, X·Y축 표시를 조절합니다. 확대 상태에 따라 표시할 점을 줄여도 격자는 캔버스 좌표를 따라 움직입니다.
- **선택·이동·정리** — 선택 도구로 객체를 클릭하거나 영역을 드래그해 여러 개를 선택합니다. 객체를 끌거나 방향키로 이동하고, 크기·회전 핸들과 우측 속성 패널로 배치를 조정합니다. 여러 객체를 함께 움직일 때는 그룹으로 묶을 수 있습니다.
- **스타일과 깊이** — 선택한 객체의 종류에 따라 채우기, 테두리, 모서리, 그림자, 글꼴과 글자 크기를 조절합니다. 겹친 객체는 앞뒤 순서와 깊이를 바꿔 정리합니다. 잠긴 객체를 수정하려면 잠금 해제 권한이 필요합니다.
- **실행 취소와 단축키** — 하단 실행 취소 버튼 또는 Ctrl/⌘+Z로 내 최근 객체 생성·삭제·이동·크기·스타일·내용 변경을 되돌립니다. 이력은 현재 작업 화면에 머무는 동안 유지되며 복원에도 객체 권한이 적용됩니다. Ctrl/⌘+1은 선택, Ctrl/⌘+2는 손, Ctrl/⌘+3은 펜, Ctrl/⌘+4는 지우개를 엽니다. [단축키 전체 목록](CANVAS_TOOL_SHORTCUTS.md) · [실행 취소 동작](CANVAS_UNDO.md)

### 글쓰기, 그리기, 파일과 데이터

- **펜·지우개·레이저 포인터** — 펜으로 자유롭게 그리고 지우개로 드로잉을 수정합니다. 설명할 부분을 잠시 가리킬 때는 참가자에게 위치가 전달되는 레이저 포인터를 사용합니다.
- **도형·연결선** — 도형을 배치하고 **연결** 도구에서 출발 객체와 도착 객체를 선택합니다. 시스템 설계에서는 서비스마다 도형을 두고 연결선으로 요청 방향이나 처리 순서를 표시할 수 있습니다.
- **내용·포스트잇** — 회의 메모는 포스트잇에, 설명이나 문서는 **내용** 객체에 작성합니다. 내용 형식으로 일반 텍스트, Markdown, LaTeX, 코드를 선택할 수 있습니다. HTML 객체는 자체 미리보기를 제공하며 CSS·JavaScript 객체를 연결해 스타일과 동작을 구성할 수 있습니다.
- **파일과 링크** — **미디어** 도구에서 사진, PDF, 동영상·GIF 또는 링크를 추가합니다. 예를 들어 리뷰할 PDF 옆에 질문을 포스트잇으로 배치하거나 작업 지시와 참고 영상을 한 영역에 모을 수 있습니다.
- **테이블·시트·그래프** — 직접 입력할 데이터는 테이블로, 기존 파일은 **데이터 시트**에서 CSV·TSV·XLSX로 가져옵니다. **그래프** 객체를 추가하고 속성에서 데이터와 표시 설정을 편집해 비교 자료를 만듭니다.
- **값 객체** — **연속 값**의 슬라이더와 수치 입력으로 실수 값을 조절합니다. **이산 값**은 정수, 버튼, 선택, 문자 입력을 제공합니다. 값 객체를 다른 계산·실행 객체에 연결해 입력을 바꿔가며 결과를 확인할 수 있습니다. [캔버스 도구 구현](../src/canvas/canvasToolCatalog.js)

### 프로젝트 관리, 발표, 수업

- **이슈와 칸반** — **프로젝트 관리** 객체를 놓고 **이슈 생성**에서 제목, 설명, 담당자, 우선순위, 기한, 스토리 포인트 등을 입력합니다. 칸반 열 사이에서 작업 상태를 옮기거나 검색과 담당자 필터로 작업을 찾습니다. **워크플로 관리**에서 상태와 승인 여부를 설정할 수 있습니다.
- **스프린트와 로드맵** — 목표와 기간을 지정해 스프린트를 생성하고 백로그 작업을 배정합니다. 진행 중에는 완료율과 완료 포인트를 확인하고, 종료 시 미완료 작업을 백로그로 돌릴 수 있습니다. 일정이 있는 작업이나 마일스톤은 타임라인에서 확인합니다. [프로젝트 관리 구현](../src/canvas/projects/ProjectObject.jsx)
- **프레임 발표** — 프레임을 직접 배치하거나 객체를 선택해 프레임을 만듭니다. 프레임 이름을 지정하고 발표 순서대로 연결합니다. 객체에 할당 프레임, 애니메이션 효과와 우선순위를 설정한 뒤 발표에서 스페이스바로 다음 묶음을 재생합니다. 특정 프레임은 **보기 링크 복사**로 공유할 수 있습니다. [발표 설정 구현](../src/canvas/portfolio/PortfolioControls.jsx)
- **타이머와 공동 문제** — 활동 시간은 타이머 객체로 표시합니다. **문제 객체 → 문제 수정**에서 객관식 또는 주관식과 배점을 설정하고 **공동 답안 → 답안 제출**로 제출합니다. 쓰기 권한이 있는 참가자가 **직접 채점**에서 점수와 피드백을 저장합니다. 문제당 답안 하나를 참가자가 공유하므로 조별 풀이와 토론에 활용할 수 있습니다. [문제 객체 사용법](CANVAS_QUESTIONS.md)

### 참여자, 권한, 채팅과 통화

- **입장과 그룹 권한** — 관리자는 캔버스의 공개 여부와 비밀번호를 관리하고, 참여자를 그룹에 배정합니다. 그룹의 읽기·쓰기·실행 권한을 각각 설정하고 객체가 공유될 그룹을 지정할 수 있습니다. 참가자가 보는 객체와 사용할 수 있는 기능은 이 권한을 따릅니다.
- **봇 참여 계정** — 권한 있는 관리자는 봇을 생성해 그룹에 배정하고, 발급된 자격 증명을 다운로드하거나 토큰을 교체·폐기할 수 있습니다. 봇에도 배정한 그룹의 권한을 적용합니다. [그룹 및 봇 관리](CANVAS_ACCESS_MANAGEMENT.md) · [캔버스 비밀번호](CANVAS_PASSWORD_ACCESS.md)
- **채팅·댓글·멘션** — **채팅 · 통화 → 채팅**에서 텍스트 채널을 열고 메시지를 보냅니다. 특정 객체에 관한 검토는 객체를 선택한 뒤 **댓글**을 열어 기록합니다. 멘션 알림에서 해당 채널 메시지나 객체 댓글로 이동할 수 있습니다.
- **음성 통화와 화면 공유** — **통화** 탭에서 음성 채널을 선택하고 **통화 참여**를 누른 뒤 브라우저의 마이크 권한을 허용합니다. 마이크 음소거, 수신 음소거, 상대방별 볼륨 설정과 화면 공유를 사용할 수 있습니다. 통화에는 HTTPS와 마이크 권한이 필요하며 네트워크에 따라 운영 환경의 TURN 설정이 필요합니다. [통화 사용법 및 접속 조건](CANVAS_VOICE.md)
- **시점 따라가기** — 참여자 목록에서 대상 사용자의 **관전하기**를 누르면 그 사용자의 시점을 따라갑니다. **관전 종료**로 자신의 작업 화면에 돌아옵니다. 리뷰나 시연 중 진행자가 보고 있는 캔버스 위치를 함께 따라갈 때 사용할 수 있습니다. [시점 공유 구현](../src/components/canvas/CanvasPresenceStack.jsx)

### 코드 실행, 노트북과 AI 에이전트

- **코드 객체·실행 객체·실행 결과 객체** — 코드 객체에 소스를 작성하고 실행·결과 객체를 연결한 뒤 실행합니다. 예를 들어 입력 값에 따라 결과가 바뀌는 계산 흐름을 보드 위에서 구성하고 출력 객체로 결과를 확인할 수 있습니다.
- **노트북과 터미널** — **주피터 노트북** 객체에서 셀을 편집하고 개별 Python 셀을 실행해 표·그래프·이미지 출력을 확인합니다. 터미널은 캔버스 VM의 셸을 열 때 사용합니다. 실행에는 서버 런타임과 해당 객체의 실행 권한이 필요합니다.
- **실행 환경** — 상단 **실행 환경**에서 C, C++, Python, Java, JavaScript, Shell의 설치된 컴파일러·인터프리터와 옵션을 확인할 수 있습니다. 설정은 같은 캔버스에서 공유되며 변경에는 쓰기와 실행 권한이 모두 필요합니다. 언어 설정을 바꾸면 해당 언어의 변수와 함수가 초기화될 수 있습니다. [언어별 설정과 동작](runtime-environments.md)
- **에이전트 입력과 분기** — **에이전트 입력**에서 텍스트, 이미지, 오디오, 동영상, PDF를 받도록 구성하고 **라우터**로 연결합니다. 입력 형식에 따라 분기하거나 설정한 판단 방식으로 담당 에이전트를 고릅니다.
- **에이전트 실행과 출력** — **AI 에이전트 객체**에 프롬프트와 모델 설정을 지정하고 결과를 **에이전트 출력**에 연결합니다. 여러 에이전트의 작업은 **오케스트레이터**로 조율할 수 있습니다. 외부 모델 호출에는 공급자 설정과 자격 증명이 필요합니다. 미리 지정한 응답으로 연결을 점검하려면 모형 에이전트만으로 테스트 흐름을 구성합니다. [에이전트 실행 구현](../src/canvas/agents/runMultiAgentGraph.js)

### JSON 가져오기와 GitHub 변경 이력

1. 상단 **캔버스 코드**에서 JSON을 편집하거나 파일을 가져옵니다. **변경 검토**에서 추가·수정·삭제될 객체를 확인한 뒤 **검토한 변경 적용**을 누릅니다. 내려받은 JSON은 다른 캔버스에서 다시 가져오거나 Git으로 관리할 수 있습니다. [Canvas as Code](canvas-as-code.md)
2. 상단 **변경 이력 → 저장소 연결**에서 GitHub 저장소, 브랜치, 파일 경로와 토큰을 설정합니다. 스냅샷을 검토한 뒤 로컬 커밋과 푸시를 진행하거나 기존 커밋을 코드로 검토할 수 있습니다.
3. 권한이 있는 사용자는 브랜치별 작업 캔버스를 생성하거나 열고, PR을 생성하거나 변경 이력에서 이전 커밋을 복구할 수 있습니다. 관리자는 병합을 수행할 수 있습니다. 작업에는 캔버스에서 위임된 권한과 해당 GitHub 저장소 권한이 함께 적용됩니다.
4. JSON 스냅샷은 캔버스 객체와 리소스 주소를 기록합니다. 채팅·댓글·VM 파일은 캔버스 서비스에 있으며, 이미지·PDF를 다시 열 때는 참조 주소와 리소스 열람 권한이 필요합니다. [저장소 연결·커밋·브랜치·복구](CANVAS_GITHUB.md)

| **DB** | MS SQL Server는 계정·세션·캔버스 배정 및 서버 메타데이터를 저장합니다. RedisJSON은 활성 캔버스 문서를 보관하고 Sentinel은 Redis 장애 조치를 지원합니다. Elasticsearch는 캔버스 문서의 장기 저장과 서버 로그에 사용합니다. [저장소 구성](../../project-agora-DB/docker-compose.yml) · [DB 운영 안내](../../project-agora-DB/README.md) |

편집 시 FE는 Wall의 Phoenix 브로커에 변경을 보냅니다. BE의 C++ 서비스가 요청 권한을 확인하고 Redis에 반영하면 브로커가 저장 결과와 순번이 붙은 변경을 전달합니다. 재접속하거나 변경 순번이 누락되면 FE가 서버에 재동기화를 요청합니다. 동시 텍스트 편집은 Automerge로 병합하며 음성·화면 공유 미디어에는 WebRTC를 사용합니다. [캔버스 서버 동기화](canvas-server-sync.md)
