# 원점의 보이지 않는 연결선 장애물

2026-11-04, 캔버스 2102에서 원점 부근의 보이지 않는 영역을 연결선이 우회한다는 신고를 조사했다.

저장 문서에는 화면용 객체 25개와 비표시 `chat_room` 데이터 2개(일반 채팅방과 객체 댓글방)가 있었다. 화면과 공간 인덱스는 채팅방을 제외했지만 `connectorGeometry`는 `kind !== 'connector'`인 모든 데이터를 장애물로 사용했다. 좌표와 종류가 없는 두 채팅방이 각각 `(0,0)`부터 `320×120` 캔버스 단위의 기본 사각형으로 계산되어 같은 영역에 겹쳤다. 따라서 객체 목록·테두리에는 없으면서 연결선만 피하는 현상이 생겼다.

표시 가능한 객체 종류를 공통 판정으로 통일하고, 연결선의 장애물·양 끝 대상 및 공간 인덱스에서 비표시 데이터를 제외했다. 채팅·댓글 기록과 사용자 객체, 접근 권한은 변경하지 않았다.

실제 2102 메타데이터를 원점 교차 경로에 적용해 수정 전에는 경로가 바뀌고 수정 후에는 바뀌지 않음을 확인했다. 실제 도형이 같은 위치에 있으면 계속 우회하며, 객체가 메타데이터로 전환될 때 기존 공간 영역도 제거하는 회귀 검사를 추가했다. 전체 프런트엔드 테스트 324개 통과.
