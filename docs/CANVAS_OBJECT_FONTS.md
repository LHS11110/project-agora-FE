# 객체별 글자 크기

객체 하나를 선택하고 오른쪽 설정 패널의 **글자 크기**에서 2~256px을 입력합니다. Enter 또는 입력창 밖을 클릭하면 저장합니다. 기존 그룹별 쓰기 권한과 객체 잠금이 적용됩니다.

모든 객체 종류가 `fontSize`를 저장할 수 있습니다. 텍스트·코드·수식·포스트잇·표의 기존 동작을 유지하면서, 문제 객체·실행/결과 객체·그래프·연결선 라벨·사용자 그룹·이미지 캡션·PDF 제목/안내·링크의 텍스트에도 적용합니다. 제목·본문·보조 문구의 상대적인 크기 차이는 유지합니다. 텍스트를 표시하지 않는 도형/드로잉에도 설정값을 저장할 수 있지만 도형이나 선 자체의 크기는 바꾸지 않습니다.

객체 영역 크기는 별도 설정입니다. 자동 높이인 객체는 글자가 커지면 기존처럼 내용에 따라 높이가 늘어날 수 있습니다. 이미지와 PDF 원본에 포함된 글자, 외부 웹/동영상 플레이어 내부의 글자는 변경하지 않습니다. 그래프의 글자는 기존 SVG 좌표계 안에서 크기가 조정됩니다.

## 구현

- `supportsObjectFontSize`: 모든 객체 종류에 설정을 제공합니다.
- 기존 텍스트 계열은 원래의 콘텐츠 스케일을 한 번만 적용합니다.
- 다른 객체는 `--object-font-factor`로 글꼴만 조정합니다. 기존 링크 콘텐츠 스케일과도 중복 적용하지 않습니다.
- 값이 없는 객체는 이전 기본 디자인을 유지합니다.
- 기존 `fontSize` 필드를 브로커를 통해 저장·공유하므로 별도 데이터베이스 마이그레이션은 없습니다.
- 객체별 CSS 변수로 처리하며 새 폴링 타이머나 객체 전체를 순회하는 DOM 측정을 추가하지 않습니다.

단위 테스트는 `tests/objectFontSize.test.js`, 브라우저 검증은 `tests/integration/canvas-object-fonts.mjs`입니다. 글자 크기 변경 전후의 실제 스타일/스케일 비율, 객체 위치·크기 보존, 모든 종류의 설정 노출, 다른 화면의 반영과 재접속 복원을 검사합니다.
