# 캔버스 그래픽 품질

설정 패널의 **그래픽 품질**에서 낮음·보통·높음을 선택한다. 모든 도구에서 표시되고 즉시 적용된다. 기본값은 가장 빠른 **낮음**이며 브라우저의 `agora_canvas_graphics_quality`에 기기별로 저장한다.

| 품질 | 화면 렌더링 최대 배율 | 객체 래스터 최대 배율 | 장면 래스터 픽셀 예산 |
| --- | ---: | ---: | ---: |
| 낮음 | 1 | 1.5 | 800만 |
| 보통 | 1.5 | 2 | 1,600만 |
| 높음 | 2 | 3 | 3,200만 |

화면 배율은 실제 기기의 DPR 이하로 제한한다. 일반 DPR 1 화면에서도 보통·높음은 객체 래스터의 정밀도를 높인다. 확대율, 객체 개수, 객체 크기에 따라 래스터 배율을 제한하며, 객체당 최대 200만 픽셀과 최대 변 길이 4,096 제한은 유지한다. 따라서 작은 객체가 많은 장면에서는 예산 상한 때문에 품질 차이가 줄어들 수 있다.

GPU 렌더러, CPU/Worker 폴백, 실시간 드로잉에 같은 화면 해상도를 적용한다. 변경 시 이미 준비된 객체도 재생성한다. 그림자·색상·손그림 스타일·텍스트 내용 등 객체 데이터는 변경하지 않는다. 높은 품질은 GPU·메모리 사용량과 준비 비용이 늘어나므로 대량 객체에는 낮음을 권장한다.

검증: Node 테스트 104개와 production 빌드 통과. 실제 GPU를 사용한 DPR 2 브라우저에서 기본 낮음, 1→1.5→2→1 렌더링 배율 전환, 래스터 재생성, 새로고침 후 선택 유지, 객체 내용 보존, 낮음의 드로잉 표면 1배 해상도를 확인했다.

Project Orchestra의 production 정적 exporter로 배포했고 실제 배포 주소에서도 위 품질 전환과 저장 검증을 반복해 통과했다.

배포 후 낮음 설정에서 모든 객체가 화면 안에 있는 10만 개 기본 도형 장면의 드로잉을 300프레임 측정했다. 평균 59.6 FPS, p95 23.8ms, 최대 46.2ms, 33ms 초과 4/300이었다. Chrome 155, RTX 3060 Ti, 1800×1100, DPR 1 조건이며 rAF 간격 측정이다. 성능 측정의 저장 ACK는 모의 처리하므로 실제 네트워크 지연을 포함하지 않는다. 모든 프레임의 60 FPS를 보장하는 결과는 아니다.
