# 노트북과 격자 배치

## 사용 방법

자료·계산 도구의 **주피터 노트북**을 선택하고 캔버스에 놓는다. 객체를 선택해 코드/Markdown 셀을 편집하고 ▶ 또는 Shift+Enter로 셀을 실행한다. **모두 실행**은 코드 셀을 위에서부터 순서대로 실행하고 오류가 나면 중단한다. **커널 초기화**는 해당 노트북의 변수·함수를 지운다. `.ipynb` 가져오기는 소스 셀을 읽으며 기존 파일의 출력은 가져오지 않는다. 내보내기에는 현재 출력도 포함한다.

Python 셀의 stdout, 오류, pandas 표(HTML), matplotlib 그래프(PNG), 이미지와 SVG를 표시한다. HTML/SVG 출력은 스크립트·네트워크·상위 화면 접근을 허용하지 않는 iframe 샌드박스에 표시한다. 셀, 출력, 실행 상태는 저장 승인 후 공유되며 새 참가자도 저장된 결과를 받는다. 쓰기 권한으로 셀을 편집하고 읽기·실행 권한으로 실행한다. 환경 준비는 실행 환경 관리 권한이 추가로 필요하다. 잠긴 객체에서도 실행할 수 있으며 내용은 수정할 수 없다.

설정 패널에서 **격자 간격**(1~10000 캔버스 단위)을 입력하고 **격자에 맞춰 배치**를 켠다. 끄면 자유롭게 배치한다. 생성과 단일·다중 드래그에 적용하며 다중 이동은 상대 간격을 보존한다. 드로잉 선 자체는 자유 필기를 유지하고 기존 선을 이동할 때만 맞춘다. 방향키의 픽셀 단위 이동과 명시적인 수치 편집은 그대로 사용한다. 격자 설정은 개인 화면 설정이며 결과 객체 위치는 공유한다. 축소 시 격자 점은 실제 간격의 정수 배수로 생략해 밀도를 제한하고 큰 간격에서도 점 크기와 렌더링 표면 크기를 제한한다.

## 실행 환경

브라우저 → 인증된 Spring API → Unix 소켓 런타임 관리자 → VSOCK → VM의 비특권 Jupyter 클라이언트 → IPython 커널 경로를 사용한다. 별도 공인 포트나 Jupyter 서버를 열지 않는다. 노트북별 커널을 사용하고 최근 4개 커널을 메모리에 유지한다. 더 많은 노트북을 실행하면 가장 오래 사용하지 않은 커널부터 정리한다. VM 중단·재시작·Python 환경 변경 때 메모리 상태는 초기화되지만 셀·저장된 출력과 `/workspace` 파일은 유지된다.

기본 Python 3.12 이미지에는 jupyter-client, ipykernel, pandas, matplotlib를 포함한다. 다른 Python 버전 또는 이전 VM에서는 **환경 준비**로 선택된 인터프리터에 필요한 패키지를 준비한다. 이전 VM에 새 에이전트를 적용할 때는 이 버튼으로 VM이 한 번 재시작될 수 있다. 기존 파일은 보존한다. 기존 사용자 VM은 배포 중 강제로 재시작하지 않았다.

코드 셀은 기존과 같이 15초 제한을 적용한다. 대화형 `input()`은 비활성화하며 명확한 Jupyter 오류를 표시한다. 셀당 소스 64KB, 노트북당 32셀, 실행당 rich output 약 256KB를 제한하고 넘으면 생략 표시한다. 브라우저가 실행 도중 사라진 경우 공유 실행 상태는 유효기간 후 다시 실행할 수 있도록 표시한다.

메시지 의미는 [Jupyter messaging](https://jupyter-client.readthedocs.io/en/stable/messaging.html)과 [KernelClient API](https://jupyter-client.readthedocs.io/en/stable/api/jupyter_client.html)를 따른다. FreLog의 캔버스용 노트북 UI이며 별도의 JupyterLab 화면은 띄우지 않는다.

## 검증

- 프런트엔드 단위 테스트 332개, Spring 전체 테스트 및 추가 노트북 권한 테스트, C++ 브로커 검증 테스트, 런타임 단위 테스트 50개.
- 실제 Jupyter 커널 및 실제 KVM VM에서 셀 간 변수/함수 유지, DataFrame HTML, matplotlib PNG, 커널 분리·초기화와 stdin 오류 검증.
- 운영 도메인의 실제 API와 봇 계정에서 커널 공유, 저장·브로드캐스팅, 실행 전용 권한과 회수 후 403 검증. 격리된 테스트 사용자·봇·캔버스·VM 정리.
- 두 브라우저에서 셀 편집·실행 상태·출력 공유, 재접속 복원, HTML 스크립트 차단, 격자 이동과 자유 배치 전환 검증.
