# 개발·연구용 도형과 자료 구조

**도형·연결 폴더 → 도형 → 설정 패널 → 도형 종류**에서 분야를 선택하거나 이름·용도로 검색합니다.
기존 도형과 논리 회로를 유지하면서 벡터 기호 40종을 추가했습니다. 전체 목록은 70종입니다.

| 분야 | 추가 기호 |
|---|---|
| 개발·흐름도 | 시작·종료, 입출력, 문서, 서브프로세스, 지연, UML 클래스·패키지, 서버 |
| 자료 구조 | 배열, 스택, 큐, 연결 리스트 노드, 트리 노드, 해시 버킷 |
| 수학 | 좌표축, 수직선, 벡터, 각도, 벤 다이어그램, 행렬 |
| 과학·실험 | 비커, 삼각 플라스크, 시험관, 페트리 접시, 원자 모형, 파동 |
| 공학·회로 | 저항, 커패시터, 인덕터, 접지, 전지, 연산 증폭기, 스프링, 댐퍼 |
| 입체·기하 | 평행사변형, 직각삼각형, 정육면체, 구, 원뿔, 각뿔 |

[기호 모음 PNG](symbol-catalog.png) / [벡터 SVG](symbol-catalog.svg).

도형 패널의 예시 구조 생성 기능과 예시 파일은 제거했습니다. 기존 캔버스에 삽입된 객체는 유지합니다.

## 렌더링과 저장

일반·손그림 스타일, 테두리·색상·투명도·크기·회전, 기존 연결선과 서버 저장 경로를 사용합니다.
회로와 좌표축 등 열린 기호는 선으로 그리고, 채우기는 닫힌 몸체에만 적용합니다.
회로 기호의 연결선은 내부 판이나 눈금이 아니라 외부 단자 쪽 경계에서 시작합니다.
정규화된 기하 데이터를 캐시하고 SVG 미리보기와 GPU 렌더링에서 공유합니다.
기호는 도식으로 구성되며, 값과 이름은 기존 텍스트·수식·연결선 도구로 작성할 수 있습니다.

## 검증

40종의 크기·경계·채우기 영역·비율, 일반/손그림 GPU 경로 및 회로 연결 단자를 검사합니다.

구현: `src/canvas/researchSymbols.js`, `ShapePicker.jsx`.
