# FreLog UI

공통 스타일은 `src/design-system.css`에서 관리합니다. 루트 엔트리의 마지막 스타일로 불러오며, 페이지/지연 로딩 컴포넌트의 기존 규칙보다 명시적인 범위를 사용합니다.

- 바탕: 흰색 `#ffffff`, 보조 면 `#f7f7f8`, 탐색 영역 `#f9f9fb`.
- 본문: `#202124`, 보조 글자 `#60646c`. 주요 동작: `#6852d6`, 선택 면: `#f0edff`.
- DM Sans / Noto Sans KR, 데이터와 코드에는 DM Mono. 입력 13–16px, 본문 13–15px, 버튼 12–13px.
- 모서리는 입력/버튼 7–8px, 카드/패널 10–12px. 그림자는 떠 있는 패널에 한정합니다.
- 홈은 제품 미리보기와 주요 행동 중심, 탐색은 라이브러리 중심, 문서는 계층 목차와 가독성 중심으로 구성합니다.
- 모바일 로그인에서는 장식적인 제품 소개를 숨겨 인증을 우선합니다. 표는 문서 내부에서 가로 스크롤합니다.
- 캔버스는 렌더러와 객체의 글꼴·색상·좌표를 변경하지 않고 chrome만 스타일링합니다. 라이트/다크 토큰을 따로 정의합니다. 1500px 이하의 작업 영역에서는 도구 dock과 보기 설정을 다른 줄에 배치합니다.
- 배경 그라데이션이나 클릭 이펙트는 추가하지 않습니다. 도형 색, 폴더 색 등 사용자가 지정한 콘텐츠 스타일은 보존합니다.

참고: [Figma](https://www.figma.com/ui-design-tool/), [Discord](https://discord.com/blog/you-bar), [Notion](https://www.notion.com/product/projects). 브랜드 자산을 복제하지 않고 작업 공간·탐색·정보 계층의 구성을 참고했습니다.

검증: `tests/integration/design-system.mjs` (HTTP/WebSocket fixture로 데이터 격리). 홈/로그인/문서/탐색/프로필/캔버스/체험 페이지의 데스크톱·모바일 범위, 가로 넘침, 생성 다이얼로그, 프로필 입력, 계정 삭제 다이얼로그, 목차 이동, 캔버스 도구 간 충돌과 패널 토글, 다크 모드를 검사합니다. `AGORA_E2E_SCREENSHOTS=1`이면 `/tmp/agora-redesign-*.png`를 저장합니다. 인증 관련 기존 회귀 테스트도 함께 실행합니다.
