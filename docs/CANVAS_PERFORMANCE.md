# 캔버스 렌더링과 전송 최적화

## 격자

설정 패널에서 가로·세로 간격을 각각 지정한다. 단위는 캔버스 좌표의 픽셀이며, 각 값은 1~10000이다. 격자에 맞춰 배치를 켜면 두 간격으로 위치를 반올림한다. 다중 이동은 상대 배치를 보존한다. 기존 단일 간격 설정은 두 축에 같은 값으로 이전한다. 간격과 배치 모드는 사용자 브라우저에 저장한다.

## 코드 객체

선택하지 않은 코드 객체는 Canvas/GPU 캐시에 미리보기를 그린다. 객체마다 Monaco와 구문 강조 DOM을 생성하지 않는다. 선택하거나 편집하면 기존 편집 UI를 사용한다. 코드 변경, 글꼴 변경 및 실행 상태 변경은 캐시를 갱신한다. 자동 높이 코드 객체의 공간 인덱스와 선택 범위도 미리보기 높이를 따른다.

## 이동·붙여넣기·확대

- 위치 드래그 중에는 로컬 미리보기만 갱신한다. 종료 시 객체 ID 목록, 전체 이동 벡터, 시작·종료 위치를 한 작업으로 전송한다. 다른 참여자는 최종 위치를 받는다. 취소하면 저장하지 않는다. 응답이 지연되면 같은 요청을 재전송하며 서버가 중복을 제거한다.
- 붙여넣기 파싱과 ID 재할당은 Worker에서 수행한다. 최대 32개 또는 약 128KiB씩 삽입하고 프레임 사이에 양보한다. 대기 중인 전송량이 많으면 다음 배치를 늦춘다. 전체 붙여넣기는 10000개·16MiB 제한을 유지한다.
- 카메라 변환은 프레임 단위로 적용하고 React 장면 및 상세도 갱신은 합친다. 공간 검색, 미니맵, 장면 준비와 깊이별 렌더링 목록은 증분 변경을 재사용한다.
- 브로커와 `gzip-v1`을 협상한 연결은 JSON 직렬화·압축·해제를 Worker에서 수행한다. 작은 메시지와 압축 이득이 없는 메시지는 그대로 보낸다. 기존 SDK의 JSON 연결도 지원한다. 서버의 압축 해제 크기 제한은 유지한다.

## 검증

`tests/integration/canvas-performance.mjs`는 실제 편집 화면을 모의 API·브로커에 연결하여 확대, 드래그 및 점진 붙여넣기를 측정한다. `AGORA_PERF_OBJECTS`, `AGORA_PERF_KIND=code`로 데이터 구성을 지정한다. `code-raster-grid.mjs`는 코드 선택·편집과 축별 격자 저장 및 맞춤을 확인한다. `drag-endpoints.mjs`는 단일·다중 이동, 취소와 undo를 확인한다. 측정 FPS는 실행 장치와 브라우저 환경에 따라 달라진다.

## 변경되지 않은 객체와 그래픽 품질

DOM 객체는 내부 콘텐츠를 별도로 메모화한다. 위치·회전·깊이만 달라지면 바깥 프레임만 갱신하고 내부 편집기, PDF 캔버스, 미디어 요소와 터미널 세션은 유지한다. 텍스트·표·노트북 셀·실행 결과·폰트·접근 권한·편집 및 선택 상태의 변경은 해당 콘텐츠를 갱신한다. 동일한 불변 객체 쌍의 비교 결과는 WeakMap으로 재사용하며, 참조가 사라지면 GC 대상이 된다. 마크다운 파싱 결과도 React 메모화를 통해 재사용한다.

객체 크기 측정과 폰트·테마 변경은 별도로 처리한다. 다른 객체의 측정 이벤트가 코드·텍스트의 픽셀 캐시를 버리지 않는다. 연결선은 실제 경로가 같으면 라우팅 리비전이 달라져도 동일한 픽셀을 재사용한다. 화면 이동이나 최종 합성, 실제 재생·실행·입력 등에는 여전히 작업이 필요하다. 캐시는 모든 연산을 없애는 기능은 아니다.

품질을 바꾸면 래스터 및 PDF 해상도와 이미지 미리보기 크기가 갱신된다. PDF는 프로필별 픽셀 예산과 한 변 4096px 제한을 적용한다. 이미지 개요 미리보기는 낮음 96px, 보통 192px, 높음 384px를 사용한다. 낮음은 객체 그림자를 생략하고, 보통·높음은 저장된 그림자 설정을 표시한다. 원본 객체 설정은 수정하지 않는다. HTML 텍스트와 SVG는 모든 단계에서 브라우저의 기본 선명도를 유지한다. 외부 영상의 실제 스트림 해상도와 이미 생성된 이미지의 원본 해상도는 클라이언트 설정으로 높일 수 없다.

`tests/integration/object-cache-quality.mjs`는 변경 없는 코드 캐시, 객체 이동 시 콘텐츠 재사용, 품질 변경에 따른 PDF·래스터 갱신과 유휴 시 캐시 유지를 검증한다. `canvas-scene.__agoraContentCacheStats`는 내부 콘텐츠 비교 및 캐시 적중 수를 제공한다.

## 객체 복사

공간 인덱스를 갱신할 때 연결선의 양 끝 ID에 대한 인접 인덱스도 유지한다. 편집 화면의 복사는 선택한 객체와 해당 객체에 연결된 간선만 조회한다. 작은 선택은 기본 copy/cut 이벤트의 clipboardData에 즉시 기록한다. 큰 선택은 최대 32개·추정 256KiB씩 Worker로 보내 좌표 변환·텍스트 색상 추출·JSON 생성을 수행한다. 선택 객체의 저장된 공간 경계가 유효하면 복사 기준점 계산에도 재사용한다.

큰 복사는 사용자 입력 이벤트 안에서 Promise 기반 ClipboardItem을 만들고, Worker 결과가 준비되면 운영체제 클립보드에 기록한다. 브라우저 권한이 거부되면 내부 클립보드와 붙여넣기 버튼을 사용할 수 있다. 일반 입력창의 텍스트 복사는 가로채지 않는다. 잘라내기는 복사 준비가 끝난 후 원본 참조와 현재 상태를 대조하며, 준비 중 원본이 변경되면 삭제를 취소한다. 한 번에 10000개·기존 16MiB 문자열 제한은 유지한다.

동일한 선택과 원본 참조에 대해서는 마지막 직렬화 결과를 재사용한다. 캐시의 원본 참조는 WeakRef로 보관하여 삭제된 객체의 CRDT 문서를 불필요하게 붙잡지 않는다. Worker는 캔버스 이탈 시 종료한다.

단일 객체 복사 전처리를 같은 실행에서 9회 측정한 중앙값(클립보드 I/O·인덱스 구축 제외):

| 전체 객체 | 전체 순회 | 인접 인덱스 |
|---|---:|---:|
| 1000 | 0.375ms | 0.014ms |
| 10000 | 3.618ms | 0.008ms |
| 100000 | 56.631ms | 0.008ms |

`tests/integration/object-copy.mjs`는 관련 연결선, Worker 복사 및 CRDT 글자 색상, 반복 복사 캐시, 변경 중 잘라내기 취소, 실제 ClipboardItem 쓰기와 권한 거부 시 내부 붙여넣기를 확인한다. `AGORA_PERF_OBJECTS=100000`으로 대량 캔버스에서 실행할 수 있다. 측정은 테스트 장치와 데이터 구성에 따라 달라진다.
