## 1. 문서 목적, 개정 이력 및 추진 일정 (WBS)

### 1.1 문서 목적
본 문서는 **Project Agora (FreLog)**의 초기 요구사항 분석 산출물(`refs/요구사항 추적표/` 5종 Excel, `refs/정의서 및 설계서/인프라_및_아키텍처_정의서.xlsx`, `refs/End_Point_04주차_계획서.hwp`)로부터 중간 설계 전환점(`refs/프로젝트중간보고서_End_Point.hwp`, 2026-10-13)을 거쳐 최종 6개 저장소 구현체에 이르기까지의 **모든 기능 요구사항(FR)**, **정량적 비기능 요구사항(NFR)**, **1:1 통합 요구사항 추적표(Full RTM)**, 그리고 **통합 테스트 결과 명세**를 단일 문서 체계로 통합 정의한다.

초기 기획 대비 실제 아키텍처 고도화 과정에서 변경·확장된 설계 결정(`/api/v1/*` → `/api/*`, 직접 C++ WebSocket → `Nginx → Phoenix Broker → C++17` Hostless 구조, PixiJS/RBush → Rust/`wgpu 24.0` WASM + `CanvasGridIndex`, 24시간 단일 JWT → 15분 Access + 14일/30일 Refresh 쿠키 로테이션, EXAONE/VM CLI 제거 → In-Process MCP Local Gemma `gemma4:12b` + 승인 상용 API)을 축약 없이 **1행 1ID 원칙**으로 추적한다.
