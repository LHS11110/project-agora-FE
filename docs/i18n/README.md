# 한국어·영어 UI

홈과 로그인 화면의 언어 선택 메뉴, 워크스페이스 탐색 패널의 메뉴에서 한국어 / English를 선택합니다. 캔버스 탐색 패널을 접으면 왼쪽 아래에 언어 메뉴가 남습니다. 모바일에서는 상단 메뉴에서도 선택할 수 있습니다.

- 첫 방문은 브라우저 언어를 사용하며 미지원 언어는 한국어로 대체합니다.
- 선택한 언어는 `frelog_locale`에 저장되고 같은 브라우저의 다른 탭에도 적용됩니다. 브라우저 저장소가 차단되어도 현재 탭에서 전환할 수 있습니다.
- HTML `lang`, 입력 안내, 접근성 레이블, 도구·도형·관계 표기·설정·기술 문서을 번역합니다. 프로필 가입일과 채팅 시각도 해당 언어로 표시합니다.
- 사용자가 작성한 캔버스 이름·설명·객체 내용·코드·채팅·닉네임과 저장된 예시 객체는 원문을 유지합니다. 제품 기술 문서는 화면 문구와 함께 번역합니다.
- 언어 변경은 서버 요청, 캔버스 재접속 또는 저장을 발생시키지 않습니다. 저장 중인 편집과 로그인 폼을 초기화하지 않습니다.

## 구현

`src/i18n/locale.js`는 언어 정규화, 저장, 탭 간 변경 알림 및 named interpolation을 담당합니다. UI 컴포넌트는 `useUiLocale()`로 변경을 구독하고 `ui('한국어 원문')`으로 화면 문구만 번역합니다. 사용자가 입력한 문자열을 `ui`로 감싸지 않습니다. 동적 문구는 `ui('캔버스 {id}', {id:canvasId})`처럼 전달합니다.

번역은 `src/i18n/en.js`에 모읍니다. 미등록 문구는 한국어 원문으로 표시합니다. 도형 종류, 화살표 머리, 도구 ID와 저장 형식은 언어에 관계없이 동일합니다. 도형 검색은 원문과 번역 이름을 함께 검색하며 언어 변경 시 필터를 갱신합니다.

## 검증

```bash
node --test tests/*.test.js
npm run build
AGORA_BASE_URL=https://your-host AGORA_SESSION_FILE=/private/session.json node scripts/audit-ui-locale-browser.mjs
AGORA_SESSION_FILE=/private/session.json node scripts/test-i18n-browser.mjs
```

브라우저 검증은 읽기 전용입니다. session JSON은 `token`, `user`, `canvas_id`를 포함하며 비공개 파일로 제공해야 합니다. 홈·로그인·새로고침·탭 간 변경·입력 유지와 실제 캔버스의 변경 없는 언어 전환, 소켓 유지, 두 언어 도형 검색을 확인합니다.

번역 누락 회귀 검사는 정적 UI 문구·접근성 레이블·동적 템플릿, 홈 자료와 언어 목록의 번역, 보간 변수 일치를 검사합니다. 브라우저 검사는 실제 렌더링된 문구를 확인하며 캔버스에 작성한 내용은 검사 대상에서 제외합니다. 도형의 예시 구조 생성 기능은 제거되었습니다.
