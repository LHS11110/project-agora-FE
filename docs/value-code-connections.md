# 값 객체와 코드 연결

- 값 → 코드: 현재 값을 표준 입력 한 줄로 전달한다. 연결이 여러 개면 화면 위쪽, 왼쪽, ID 순으로 결합한다. 실수·정수·버튼은 숫자, 선택형은 선택한 항목 문자열, 텍스트형은 입력 문자열이다.
- 코드 → 값: 성공적으로 종료한 코드의 최종 stdout을 값으로 반영한다. 부분 출력으로 값을 갱신하지 않는다. 숫자는 단일 숫자와 범위를 검증하고 버튼은 0/1만 허용한다. 선택형은 정확한 항목 이름을 우선하고 없으면 인덱스를 받는다. 텍스트형은 마지막 줄바꿈 하나를 제외한 출력이다.
- 코드 → 값 → 코드 연결은 위상 정렬하고 갱신된 값을 다음 코드의 stdin으로 사용한다. 순환 연결은 실행 전에 거절한다.
- 값 객체 수정은 현재 연결을 재확인하고 객체 쓰기 권한 및 잠금을 검사하여 기존 캔버스 변경 경로로 공유한다. 읽기 전용 값 객체는 자동 수정할 수 없다.
- 기존 표준 입력 64KiB 및 값 객체의 범위·텍스트 길이 제한을 유지한다. 연결되지 않은 코드는 기존 입력 정책을 따른다.

## HTML 렌더링 객체 연결

값 객체의 설정에서 이름을 `speed`로 정하고 `값 → HTML` 방향으로 연결한다. HTML은 초기 스크립트부터 값을 읽을 수 있다. 숫자는 number, 선택형·텍스트형은 string, 버튼은 0/1이다.

```html
<strong id="speed-label"></strong>
<script>
  function render() {
    document.getElementById('speed-label').textContent = `속도: ${canvasValues.speed}`;
  }
  render();
  addEventListener('canvasvalueschange', render);
</script>
```

`speed`처럼 영문 JavaScript 식별자로 쓸 수 있고 브라우저 전역 이름과 충돌하지 않으면 `speed`로 직접 읽어도 된다. 한글·공백이 있는 이름은 `canvasValues['이름']`을 사용한다. `window`·`document` 등 기존 브라우저 전역은 덮어쓰지 않는다. 값은 읽기용이며 HTML에서 변경해도 캔버스 값 객체로 역전송하지 않는다.

값 변경·연결 제거·이름 변경은 iframe을 재시작하지 않고 전달한다. HTML 또는 연결된 CSS/JS 코드 변경은 기존처럼 미리보기를 다시 구성한다. 같은 이름을 여러 값 객체가 사용하면 연결 객체 ID 정렬상 첫 연결을 사용하므로 서로 다른 이름을 권장한다. 빈 이름은 전달하지 않는다. 기존 sandbox와 CSP를 유지하며 외부 네트워크 권한을 추가하지 않는다.
