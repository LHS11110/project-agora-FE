# 연결선의 ERD 관계 표기

연결선을 선택하고 설정 패널의 **선택한 화살표 스타일 → 시작 머리 / 끝 머리 → ERD 관계**에서 선택합니다.
연결 도구에서는 **새 연결 스타일**에 같은 설정이 있습니다. 일반 도형 화살표에도 사용할 수 있습니다.

| 표기 | 설정 값 | 의미 |
|---|---|---|
| 정확히 하나 (1) | `erd-one` | 이중 막대 |
| 없거나 하나 (0..1) | `erd-zero-one` | 빈 원 + 막대 |
| 하나 이상 (1..N) | `erd-one-many` | 막대 + 갈퀴 |
| 없거나 여러 개 (0..N) | `erd-zero-many` | 빈 원 + 갈퀴 |

각 끝의 표기는 반대편 객체 하나와 연결될 수 있는 해당 쪽 객체의 개수입니다.
양 끝을 독립적으로 조합해 1:1, 1:N, N:M과 선택 관계를 표현합니다.
예를 들어 시작의 `erd-one`과 끝의 `erd-zero-many`는 시작 객체 하나에 끝 객체 0..N개가 연결되는 관계입니다.

머리 크기 설정을 그대로 사용하며, 시작·끝 방향, 곡선과 일반·손그림 스타일에 적용됩니다.
선은 선택 관계의 빈 원을 통과하지 않습니다. 짧은 연결선에서는 양 끝을 함께 축소합니다.
SVG·미리보기·Pixi 렌더링은 같은 기하 데이터를 사용합니다.

기존 `startHead` / `endHead` 문자열 필드를 사용하며 캔버스 코드 내보내기·가져오기와 서버 저장에 포함됩니다.

검증: Node 테스트 186개, 배포 빌드 통과. 실제 브라우저에서 일반·손그림 연결선 8개에 네 가지 표기를
저장하고, 인스펙터에서 시작·끝을 변경한 뒤 새로고침하여 유지됨을 확인했습니다. 서버 거절·브라우저 오류는 없었습니다.
Project Orchestra로 정적 프런트엔드를 배포했고 임시 시험 캔버스는 제거했습니다.
