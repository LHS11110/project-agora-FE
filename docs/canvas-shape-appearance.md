# 다각형 꼭짓점·모서리와 채우기 투명도

도형 도구의 **다각형**에서 꼭짓점을 3~64개로 지정할 수 있습니다. 삼각형·오각형·육각형과 별도 꼭짓점 수를 변경할 수 있으며 별은 바깥쪽 꼭짓점을 셉니다. 각진 도형은 **각지게 / 둥글게**를 선택합니다. 테두리를 켜면 **도형 테두리 굵기**에서 0.5~64px을 입력할 수 있습니다(기본 2.5px). 일반 화살표에도 선 굵기가 적용됩니다. 새 도형의 설정과 선택한 기존 도형의 설정을 모두 지원합니다.

내부 채우기의 투명도는 0%가 기존 채우기, 100%가 채우기 없음입니다. 기본 스타일에서는 채우기 알파만 변경하고 테두리를 유지합니다. 손그림에서는 투명도로 빗금 간격을 조절하고, 별도의 **빗금 진하기**(0~100%)로 선의 불투명도를 조절합니다. 진하기 기본값은 80%이며, 100%에서는 주 빗금이 불투명하게 그려집니다. 진하기를 올려도 선 수나 간격은 바뀌지 않습니다. 설정이 없는 기존 손그림 도형도 기본 80%로 더 진하게 표시합니다. 기존 도형은 새 필드가 없어도 기존 모습으로 표시됩니다.

- `vertexCount`: 정수 3~64. 삼각형 3, 오각형·별 5, 육각형·다각형 6이 기본값입니다.
- `cornerStyle`: `sharp`(기본) / `rounded`. 닫힌 다각형 모서리에 제한된 샘플 수의 이차 곡선을 사용합니다.
- `strokeWidth`: 도형 테두리 굵기 0.5~64px. 두꺼운 선의 래스터 여백·공간 인덱스·선택 범위도 함께 반영합니다.
- `sketchFillOpacity`: 손그림 빗금의 불투명도 0~1, 기본 0.8. 일반 스타일과 화살표 머리의 기존 빗금에는 영향을 주지 않습니다.
- `fillOpacity`: 0~1, 기본 1. UI 투명도와는 반대 방향이며 손그림에서는 밀도입니다.

공유 외곽선을 사용해 캔버스, 검색 미리보기, 연결 화살표의 도형 경계가 일치합니다. 세 설정은 호스트 변경 검증·브로커 동기화·저장·Canvas as Code 왕복에 포함되며 래스터 캐시도 갱신합니다. 테두리가 없는 일반 직사각형은 투명도가 있어도 기존 단색 텍스처 공유와 직접 사각형 그리기 경로를 사용합니다. 둥근 모서리는 외곽선 래스터 경로를 사용하고, 빗금은 기존 선 수 제한을 유지합니다.

검증:

```bash
node --test tests/*.test.js
PLAYWRIGHT_MODULE_PATH=/path/to/playwright-core/index.mjs node scripts/check-shape-appearance-browser.mjs
FORCE_CPU=1 PLAYWRIGHT_MODULE_PATH=/path/to/playwright-core/index.mjs node scripts/check-shape-appearance-browser.mjs
```

Chrome 검증은 실제 설정 컴포넌트로 꼭짓점·모서리·투명도를 변경하고 채우기 픽셀과 빗금 수를 검사합니다. DepthVectorLayer의 WebGL과 Canvas2D에서 반투명 직사각형 최적화 경로의 픽셀도 확인합니다. 브라우저 픽스처는 실제 캔버스 데이터베이스를 변경하지 않습니다.

## 방향키 이동

선택 도구에서 선택한 객체는 방향키 한 번에 캔버스 좌표 1px씩 이동합니다. Shift+방향키는 10px이며 줌 배율과 무관합니다. 여러 객체와 드로잉도 함께 이동하며 연결선은 연결된 객체를 따라갑니다. 연결선만 선택하면 방향키로 이동하지 않습니다.

기존 호스트의 ID 목록+이동 벡터 연산을 사용하므로 키를 누르고 있을 때 이동을 병합하고, 키를 놓거나 창의 포커스를 잃으면 남은 전송을 처리합니다. 저장과 권한 검증도 기존 경로를 사용합니다. 입력창·편집기·설정 버튼·대화상자, 편집 모드, 드래그 중, 읽기 전용 상태에서는 객체 이동을 실행하지 않습니다.

```bash
PLAYWRIGHT_MODULE_PATH=/path/to/playwright-core/index.mjs node scripts/check-keyboard-nudge-browser.mjs
```
