# 데이터 시트와 PDF 가져오기

캔버스 도구의 **미디어 → 데이터 시트**에서 CSV, TSV, XLSX를 선택하거나 파일을 캔버스에 붙여넣거나 놓는다. 기존 레이아웃을 사용하는 사용자에게도 미디어 폴더에 새 도구가 추가된다.

데이터는 편집 가능한 기존 테이블 객체로 변환한다. 첫 행은 열 이름이다. XLSX는 비어 있지 않은 모든 시트를 가져온다. 100행·30열 단위로 나누어 시트명과 범위를 표시하고 점진적으로 배치한다. 각 표는 기존 권한 검사, 저장 성공 후 브로드캐스팅, 새 참가자 스냅샷 경로를 사용한다. 원본 파일이나 Excel 서식·매크로를 저장하지 않으며 수식을 계산하는 스프레드시트 엔진은 아니다. XLSX에서 제공되는 셀 값을 읽는다.

CSV는 자동 구분자 감지와 따옴표·줄바꿈을 지원한다. UTF-8 및 BOM을 처리하고 UTF-8로 해석할 수 없는 파일은 EUC-KR로 읽는다. UTF-16LE BOM도 지원한다. 앞자리 0을 보존하기 위해 문자열로 읽는다. 파일 해석은 워커에서 수행하며 이동/닫기 시 취소하고 완료·실패·시간 초과 시 종료한다.

파일당 5MiB, 총 100,000셀, 변환 결과 2MiB, 최대 100개 표를 허용한다. 표당 240,000바이트 및 셀당 UTF-8 4,000바이트 제한을 넘으면 잘라내지 않고 명시적으로 거부한다. 처리 시간 제한은 60초다.

PDF는 서버의 기존 5MiB 제한을 유지한다. 첫 페이지 미리보기 렌더링/PNG 생성이 실패하거나 15초를 넘으면 미리보기 없이 원본을 업로드한다. 손상되거나 암호로 잠긴 파일의 파싱 오류는 안내한다. 처리 중 새 파일 선택은 안내를 표시하며, 다른 캔버스로 이동한 뒤 이전 업로드가 객체를 삽입하지 않도록 검사한다.

검증: `tests/sheetData.test.js`에서 CSV 인용·한글·줄바꿈·문자열 값, 표 분할·날짜·여러 시트·명시적 크기 거부를 검사한다. `tests/integration/shared-value-objects.mjs`는 실제 파일 입력과 워커로 CSV와 두 시트 XLSX를 가져와 다른 브라우저와 새로고침 후 값을 대조한다. PDF PNG 생성을 실패시킨 뒤 썸네일 없는 원본 업로드 및 공유를 검증한다. 테스트 API/브로커는 격리된 대역이다.

파서: [Papa Parse](https://www.papaparse.com/docs), [read-excel-file](https://gitlab.com/catamphetamine/read-excel-file). 라이선스 고지는 배포 빌드의 npm 인벤토리에 포함한다.
